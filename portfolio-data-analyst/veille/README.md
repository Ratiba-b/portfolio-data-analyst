# Système de veille

**Objectif :** suivre l'actualité des outils et méthodes data et IA, et en tirer des décisions justifiées (tableau de décisions dans la documentation du projet 1).

**Outil :** Feedly (flux RSS). _Statut : à mettre en place._

**Sources suivies**
| Source | Pourquoi |
|--------|----------|
| Documentation de Pandera : https://pandera.readthedocs.io | Validation de données |
| Dépôt Pandera : https://github.com/unionai-oss/pandera | Nouvelles versions |
| Documentation de Great Expectations : https://docs.greatexpectations.io | Qualité des données |
| Documentation de scikit-learn : https://scikit-learn.org | Détection d'anomalies, modèles |
| Documentation de SciPy : https://docs.scipy.org | Tests statistiques (Spearman) |
| Recommandations de la CNIL sur l'IA : https://www.cnil.fr | Conformité et RGPD |

**Flux à ajouter dans Feedly (à vérifier un par un) :** flux Atom des versions des dépôts GitHub de pandas, SciPy, scikit-learn et Pandera (adresse du dépôt suivie de `/releases.atom`).

**Critères de tri d'une information :** source officielle ; date ; applicable à mes données ; testable en moins d'une heure ; impact sur la fiabilité du résultat.

**Rythme :** 30 minutes par semaine.
