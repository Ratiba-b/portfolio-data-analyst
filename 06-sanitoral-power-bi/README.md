# Sanitoral : tableau de bord Power BI de suivi de projets

- `modele_tableau_de_bord.pbit` : modèle Power BI (sans les données).
- 4 pages : vue globale (carte, indicateurs), analyse des performances, suivi des projets (Gantt), présentation.
- 8 mesures DAX (écarts de coûts, de délais, de livrables ; alerte ; projets en retard) et sécurité par rôles (directeur général, pays, régional).
